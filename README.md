## Stack

- **Cloudflare Worker + KV** (Worker `workout-tracker`, KV binding
  `WORKOUT_KV`, route `workout.oedinger.stream/*`). No Pi, **no D1** —
  the Cloudflare token has no D1 scope (401 on every D1 call).
- `index.html` — האתר (עברית RTL, mobile-first, נבדק ל־390px).
- `worker.js` — ה־Worker לפריסה (נבנה מ־`worker_template.js` על ידי
  `build_worker.py`).
- `sync_workout.py` — סנכרון אימון בודד / seed ל־Worker.
- `seed.json` — האימונים הראשונים (A 16/11 + C 20/11); אימונים נוספים
  נשמרים ב־KV דרך `/api/sync`, לא בקובץ ה־seed.
- `worker_meta.json` — מטא־דאטה לפריסה.

## API

| Route | Method | Auth | Response |
| --- | --- | --- | --- |
| `/` | GET | — | `index.html` |
| `/api/workouts` | GET | — | `{workouts: [...newest first], last_by_letter: {A, C}, meta}` |
| `/api/last?letter=A` | GET | — | last workout of that letter, or 404 JSON |
| `/api/sync` | POST | Bearer `SYNC_SECRET` | `{ok, key, date, letter, count}` |
| `/api/health` (alias `/health`) | GET | — | `{ok: true}` |

All JSON responses are `application/json; charset=utf-8`, Hebrew preserved
(`JSON.stringify` directly — no ASCII escaping).

### POST /api/sync payload

```json
{"date": "2026-11-16", "letter": "A", "exercises": [
  {"name": "בק סקוואט", "load": 40, "unit": "kg"},
  {"name": "פול אפס", "reps": 12, "note": "גומייה ירוקה"}
]}
```

Validation: `date` must be `YYYY-MM-DD`, `letter` must be `A`/`B`/`C`,
`exercises` a non-empty array, each exercise with a `name` and numeric
`sets`/`reps`/`load` if present. Sets/reps are stored only when known —
never invented.

## KV schema

- `workout:<date>:<letter>` → `{date, letter, exercises: [...], updated}`
  e.g. `workout:2026-11-16:A`, `workout:2026-11-20:C`
- `meta` → `{workouts: ["workout:<date>:<letter>", ...newest first],
  last_by_letter: {A: {...}, C: {...}}, updated}`

The next-workout letter is computed from the data (opposite of the newest
logged workout: after A comes C, after C comes A) — both in the page JS
and, for the pre-workout reminder, by reading `GET /api/last`.

## Sync from chat (after a workout)

Oren sends the workout in chat (same format as before). Save it as a JSON
file in this payload format, then:

```bash
python3 sync_workout.py workout.json
```

The Bearer token is read from `.sync-secret` in this directory (never
committed — see `.gitignore`). A browser User-Agent is sent because the
Cloudflare edge 403s Python urllib's default UA.

Seed (the two workouts above, once, at first deploy):

```bash
python3 sync_workout.py --seed
```

## Build / deploy

```bash
python3 build_worker.py   # writes worker.js (index.html embedded)
```

Deploy (parent / deploy step only — **not run from here**): upload
`worker.js` with `worker_meta.json` via the Cloudflare API multipart-put
(same pattern as homework-tracker), with the KV namespace id filled in
`worker_meta.json` and `SYNC_SECRET` set as a Worker secret. The route is
`workout.oedinger.stream/*`.

**Left for deploy time (deliberately not done here):** KV namespace id
(`REPLACE_ME` in `worker_meta.json`), the `SYNC_SECRET` value, the
Cloudflare route, the GitHub repo, and the `--seed` run.

## Not in this repo

- `.sync-secret` — bearer secret for `/api/sync` (excluded, never commit).
- `worker.js` — build output (regenerated by `build_worker.py`); commit it
  only if the deploy flow expects it in the repo, as in homework-tracker.
